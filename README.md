<h3 id="project1">Project 1: Smart Storage Behavioural Intelligence System Using IoT and Machine Learning for Anomaly Detection and Real-Time Security Alerts
1	2
</h3>
<p>
 Conventional storage security systems primarily rely on mechanical locking mechanisms or basic intrusion detection methods, which are often insufficient to identify abnormal access behaviour and provide timely remote notifications. This paper proposes a Smart Storage Behavioural Intelligence System Using IoT and Machine Learning for Anomaly Detection and Real-Time Security Alerts. The proposed system employs an ESP32 microcontroller integrated with a magnetic reed switch, relay-controlled solenoid lock, DS3231 real-time clock, Firebase Realtime Database, and a WebSocket-based communication framework to monitor and record storage access activities. Access parameters such as access time, door open duration, and access frequency are continuously collected and stored in the cloud for behavioural analysis. An Isolation Forest machine learning algorithm is trained using historical access records to learn normal user behaviour and identify suspicious access patterns as anomalies. Whenever an abnormal event is detected, the system immediately generates real-time Telegram notifications and activates a local buzzer to alert the user. The integration of embedded hardware, cloud computing, and behavioural intelligence provides a cost-effective, scalable, and intelligent security solution suitable for lockers, offices, residential storage units, and other smart storage applications. Experimental observations demonstrate that the proposed system effectively distinguishes normal and abnormal access behaviour while enabling reliable real-time monitoring and rapid security response.
